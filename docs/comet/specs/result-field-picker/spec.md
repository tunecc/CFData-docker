# 结果面板字段选择清单

## Purpose

让 Web 控制台「结果操作 → 字段与顺序 → 字段选择」始终提供完整、可预期的一组可选字段，不因当前浏览器会话是否存在结果行而变化。用户在运行任务前、刷新页面后或仅查看历史统计时，都能预先勾选要导出的列；默认勾选与导出行为保持与现状一致。

## Requirements

### Requirement: 固定字段清单

字段选择 SHALL 始终渲染完整的可用字段集合：`RESULT_FIELDS` 中定义的全部内置字段（26 个，含 `IP:PORT`）加上用户当前定义的自定义字段追加在末尾。

渲染 MUST NOT 依据 `getCurrentResultRows()` 返回的结果行是否包含某字段非空值来裁剪字段清单；结果行为空时字段选择 MUST 仍列出全部内置字段。

`IP:PORT` MUST 保持始终可选；自定义字段 MUST 按用户输入顺序追加，删除自定义字段时 MUST 同步从输出顺序中移除对应键。

### Requirement: 默认勾选与输出顺序

字段清单变长 MUST NOT 改变任何格式的默认勾选：

- TXT 默认 `IP:PORT`、`数据中心`、`落地区域`；非标 TXT 默认 `IP:PORT`、`数据中心`、`源IP位置`。
- 订阅（substore）默认仅 `IP:PORT`。
- CSV 沿用现有紧凑字段顺序。

未勾选字段 MUST NOT 出现在输出顺序列表、预览与导出内容中。已保存的 `fieldOrder`（`cfdata-result-panel`）恢复时，清单中存在的键 MUST 继续按保存顺序生效；不在清单中的键 MUST 被忽略。

### Requirement: 快速按钮语义

「全选 / 全部选」SHALL 选择清单中的全部字段；当清单已全部被选中时按钮显示「全部选」并提供“恢复默认选择”提示，否则显示「全选」。

「仅 IP:PORT」MUST 把输出顺序收敛为仅 `IP:PORT`；「默认选择」MUST 恢复当前结果格式对应的默认勾选。三个按钮 MUST 在任何结果行状态下表现一致。

### Requirement: 导出与既有行为不变

导出内容拼接 MUST 保持现状：勾选但当前结果没有数据的字段输出空值，分隔符、IPv6 方括号、起始/结束行与筛选条件 MUST 不受本次改动影响。

字段清单变化 MUST NOT 改变结果面板的数据来源下拉、复制弹窗字段选择、R2 别名模板、自动上传与 GitHub 上传链路。

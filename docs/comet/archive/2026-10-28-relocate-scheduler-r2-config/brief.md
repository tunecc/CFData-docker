# 目标

把「自动调度 / R2 上传」配置从右上角 240px 宽、点击空白即关闭的设置下拉菜单中迁出，改为主页面独立的全宽「自动化」区块；同时让设置菜单在存在未保存手动输入时不被误点关闭。保留现有全部配置项、保存语义与后端行为。

# 范围

## 目录结构

### 修改

- `combined_refactor/index.html`：新增主页面「自动化」区块与样式（桌面双列、移动端单列）；从设置菜单移除调度/R2 配置；页面初始化时加载调度配置并渲染状态；设置菜单增加未保存输入保护。
- `docs/comet/changes/relocate-scheduler-r2-config/specs/automation-settings-ui/spec.md`：本 change 的完整目标规格。

### 不修改

- 不改动 Go 后端的 `get_schedule_config` / `set_schedule_config` 消息处理、配置字段、调度算法与 R2 上传逻辑。

## 现状事实

- 设置下拉菜单 `.settings-menu` 固定宽 240px，移动端最大 260px，内部以行内元素堆叠主题、缓存、管理面代理、自动调度/R2 的六个输入框与两个开关。
- 调度配置字段：启用自动调度、Cron 表达式、检测间隔（分钟）、启用 R2 上传、Worker 地址、Worker token、文件名（默认 `cfdata-targets.txt`）。
- 打开设置菜单时通过 WebSocket 请求 `get_schedule_config` 并用服务端数据覆盖表单；点击菜单外区域立即隐藏菜单，未保存输入随之丢失。
- 保存通过 `set_schedule_config`，后端校验后写入配置文件并 `reloadWebScheduler()`，随后回传带 `saved: true` 的 `schedule_config`；token 不回传，留空保存表示保留旧值。
- 调度状态（模式、下次/上次运行、上次结果、警告）由 `schedule_config` 载荷的 `status` 提供，目前只在设置菜单内显示，且仅在打开菜单时刷新。
- 页面由 Go `//go:embed` 内嵌；现有测试未覆盖 HTML/前端行为。

# 非目标

- 不改变调度算法、Cron/间隔解析规则、R2 上传重试与存储逻辑。
- 不新增「立即运行一次」「上传测试」等新功能。
- 不改变主题、管理面代理、本地缓存等其他设置项的功能与语义。
- 不改动 `get_schedule_config` / `set_schedule_config` 消息类型和配置字段名。

# 验收示例

- 以桌面宽度打开 Web 页面时，主页面直接显示独立「自动化」区块，自动调度与 R2 上传的全部 7 个字段（调度开关、Cron、检测间隔、R2 开关、Worker 地址、Worker token、文件名）及当前调度状态完整可见且可编辑，无需打开右上角设置菜单。
- 打开右上角设置菜单时，菜单中不再包含自动调度/R2 上传配置，主题切换、管理面代理与本地缓存功能仍正常可用。
- 在「自动化」区块修改输入但未保存时点击页面其他区域，已输入内容保持不变、不会丢失。
- 在设置菜单中修改管理面代理地址但未保存时点击页面其他区域，菜单保持打开；保存成功或再次点击设置按钮后才关闭。
- 修改调度字段并点击保存后，服务端保存成功，页面提示已保存并刷新调度状态（模式、下次/上次运行、上次结果）。
- 已保存过 Worker token 时，将 token 留空后保存会保留原有 token，输入框恢复「已保存，留空保持不变」提示。
- 以 ≤768px 宽度访问页面时，「自动化」表单纵向排列，无横向滚动或控件裁切，全部输入与按钮可正常操作。

# 约束与不变量

- Worker token 不回传前端；留空保存必须保留已保存的 token。
- 保存成功后必须由后端 `reloadWebScheduler()` 使新配置生效，前端不得本地伪造状态。
- 调度配置仍使用现有字段名与 `get_schedule_config` / `set_schedule_config` 消息，配置文件格式不变。
- 深色/浅色/自动主题与现有视觉风格（`section-box`、`menu-btn` 等）保持一致。
- 扫描、测速、管理面代理、配置保存/加载等其他交互不得回归。
- 移动端（≤768px）不得出现横向滚动或控件被裁切。

# 决策

- Q1 放置方式：采用主页面独立「自动化」区块（全宽 section，桌面双列、移动端单列），设置菜单只保留主题、管理面代理、本地缓存等其余设置；配置不再位于设置下拉菜单内。
- Q2 误关保护：设置菜单中的手动输入（如管理面代理地址）与已保存值不同时，点击菜单外区域不关闭菜单；保存成功或再次点击设置按钮才关闭。「自动化」区块常驻页面，点击页面其他区域不会清空或重置其未保存输入。
- 调度配置在页面初始化时加载并渲染状态；保存成功后使用服务端回传刷新状态与表单。
- 设置菜单打开时不再请求 `get_schedule_config`（改由页面初始化加载），仍按需请求 `get_management_proxy`。
